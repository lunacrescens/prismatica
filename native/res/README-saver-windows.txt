PRISMATICA SCREENSAVERS (Windows)
A calm, slow version of the Ripple Tank scene. No music, no sound, no settings.

INSTALL   Right-click the .scr file -> Install. Windows opens Screen Saver Settings with it selected;
          set the wait time and click OK. (To keep it permanently, copy the .scr somewhere it won't
          be deleted first, e.g. C:\Windows\System32, then install it from there.)
TRY IT    Right-click -> Test, or just double-click the .scr.
STOP      Move the mouse, click, or press any key.

SmartScreen may warn because the file is unsigned: More info -> Run anyway.
With more than one monitor, the picture shows on the primary display and the others go black.
Needs a graphics driver with OpenGL 3.3.
